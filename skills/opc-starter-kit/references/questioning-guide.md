# 引导式提问模板

> 本节详细说明 opc-starter-kit 的故事式提问方法论、三角验证技术和完整话术库。

---

## 核心原则

### 不问数字，引出故事

创始人天然会对数字感到防御——"你访谈了多少人？""数据是多少？"

但创始人天然愿意讲故事——"那次访谈让我重新思考了整个方向。""有个用户的情况特别严重。"

**策略**：让创始人讲故事 → 从故事里反向提取数据 → 比直接问数字更准确也更不让人防御。

### 为什么这样设计

1. **降低防御**：故事是主观的、个人的——不容易产生"被审问"的感觉
2. **发现盲区**：数字可能被选择性地记住，故事里的细节更全面
3. **交叉验证**：同一个故事从不同角度讲，自然暴露不一致
4. **提取真实数据**：故事里的细节（频率、严重度、处理方式）天然包含量化信息

## 标准提问流程

### 第一步：用开放式问题引出故事

**好问题**：
```
✅ "聊聊你和潜在用户聊的情况——有没有哪次对话让你重新思考了自己最初的想法？"
✅ "跟我讲讲你见过的最严重的那个案例——那个人的处境是什么样的？"
✅ "最近一次你亲眼看到这个问题发生在谁身上？你当时的第一反应是什么？"
✅ "有没有哪次跟用户聊完之后，你觉得'我之前想的可能不完全对'？"
```

**差问题**：
```
❌ "你访谈过多少人？请出示证据。"
❌ "这个问题发生的频率是多少？请给出数据。"
❌ "你的用户画像是什么？"
❌ "你的TAM有多大？"
```

---

### 第二步：追问细节

用户讲完一个故事后，追问具体细节：
```
"等一下——你刚才说的那个用户，他最困扰的是什么？是他自己说的还是你观察到的？"
"他当时是怎么处理这个问题的？处理完之后他是什么感觉？"
"你跟他聊完之后，你自己有什么想法？跟聊之前有什么不一样？"
```

---

### 第三步：反向提取数据

从故事中提取量化信息：
```
"从你刚才讲的情况来看——
这类问题大概 [频率] 会发生 [次数]，
每次的处理方式都是 [当前做法]，
花费大约 [时间]，造成的后果是 [影响]。
是这样吗？"
```

如果是 → 确认数据
如果不是 → 创始人会自然纠正 → 得到更准确的数据

---

### 第四步：三角验证（关键节点）

在红队关卡前和PMF判定前，要求三个角度：
```
"我需要你从三个不同角度描述同一件事：

① 讲一个具体用户的故事——ta在哪、做什么、为什么需要
② 给我一个数字——有多少用户提到过这个需求
③ 给我一个反例——有没有用户说不需要？ta的理由是什么？"
```

**三角不一致的标志**：
- 故事里有强烈的需求，但数字很小 → 可能是小众需求
- 数字很大，但反例是"所有人都不需要"→ 数字可能来自偏差样本
- 故事和反例指向不同的用户画像 → 用户画像不稳定

## 各阶段专用话术库

### 想法阶段

**发现需求**：
```
"不要说你要做什么产品——跟我说说你看到的什么让你觉得'这不对劲'？"
```

**探索替代方案**：
```
"那些现在正在处理这个问题的人，他们现在怎么做的？
有没有人已经找到了还能接受的方案？"
```

**测试差异化**：
```
"如果有人今天推出一款产品，跟你描述的一模一样——但是完全免费——
你觉得你的目标用户会在意哪些这个免费产品做不到的事？"
```

---

### MVP 阶段

**范围控制**：
```
"你刚说想加一个功能。跟我说说——有没有用户主动跟你说过'没有这个功能，
我没法用你的产品'？还是你觉得这个功能很有意义？"
```

**PMF 感知测试**：
```
"如果你的产品明天消失了——
哪个用户会第一个发现？他会是什么反应？"
```

**度量挖掘**：
```
"你现在是怎么判断'一个用户是不是真的在用产品'的？
有没有你以为是活跃用户但其实只是'登录了一下'的情况？"
```

---

### 发布阶段

**瓶颈发现**：
```
"上次你休假的时候——或者周末没看手机——
有没有什么事事后你发现'原来我不在就卡住了'？"
```

**流程有效性**：
```
"你设计的这个流程——如果新来一个人，
ta在不问你任何问题的情况下能执行到什么程度？"
```

---

### 规模化阶段

**护城河感知**：
```
"假设你最大的竞争对手明天免费了——
你的用户里，哪些人会走？哪些人会留？走的人为什么走，留的人为什么留？"
```

**领域知识**：
```
"有没有一件事，只有你（在这个行业做了X年之后）才知道——
一个外行来做你的产品一定会做错？"
```

---

## 话术红线

### 绝对不能用的提问方式

- ❌ 审问式："你做了X吗？为什么没做？"
- ❌ 考验式："你知道Y是什么吗？"
- ❌ 暗示式："你肯定已经做了Z对吧？"
- ❌ 打压式："你这个想法明显有问题……"

### 替代方式

将上述红线句式转化为：
- ✅ "我想了解你在X方面的进展。"
- ✅ "关于Y，你的理解是什么样的？"
- ✅ "Z这个环节你是怎么考虑的？"
- ✅ "我有个担心想跟你分享一下——"
